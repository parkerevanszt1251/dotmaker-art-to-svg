## What DotMaker Does

DotMaker supports a workflow that begins with pixel-style source art and produces editable vector artwork inside Illustrator. Its purpose is to rebuild dot-based images as SVG while retaining direct control over the tracing and refinement process.

The editor is useful when the source image should remain visible during reconstruction, when individual shapes require manual adjustment, or when repeated samples need to be filled in batches. It is intended for artists and designers who use Adobe Illustrator and want to turn raster-like pixel concepts into workable vector assets.

## Core Capabilities

- Turns pixel art into SVG vectors for use with Adobe Illustrator
- Accommodates workflows based on AI-generated pixel artwork
- Displays the source image as a tracing overlay

- Supports bulk filling of repeated samples
- Bridges dot-based concepts and editable vector designs

## Working with DotMaker

1. Choose a pixel art image or an AI-generated dot-art design as the starting point.
2. Load the source and turn on the overlay to keep it visible while tracing.
3. Manually trace the shapes that need the greatest level of accuracy.
4. Apply bulk sample fill when several repeated sample areas must be handled efficiently.
5. Export or move the completed SVG into an Adobe Illustrator workflow.

A standard process looks like this:

- Bring in the source artwork
- Inspect it alongside the overlay
- Trace and adjust the shapes
- Fill recurring samples in bulk
- Produce SVG for continued Illustrator editing
